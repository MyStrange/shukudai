# 宿題 — сайт для практики японского по учебнику Genki

Одностраничный self-contained HTML-сайт с тремя режимами:

- **文** — карточки перевода: русское предложение, по кнопке `答え` открывается японский вариант
- **字** — прописи кандзи: пишешь мышью или пальцем, **каждая черта проверяется сразу**; по кнопке `答え` проигрывается порядок черт и открываются чтения
- **択** — собрать слово из кандзи в предложении: предложение с пропуском, подсказка только по-русски, варианты — все кандзи выбранных уроков
- **覚** — заучивание: маленький пул из 8 кандзи прогоняется через четыре типа заданий, с повторением по интервалам

**Файл:** `genki-practice.html` (он же `index.html` для GitHub Pages)
**Деплой:** пока нигде не задеплоен, открывается локально
**Зависимости:** только Google Fonts (Geologica + Noto Sans JP), всё остальное inline

---

## Как пользоваться

- Переключатель `文` / `字` / `択` / `覚` справа от логотипа
- Выбери юниты (кнопки-пилюли `第1課`, `2`, `3`…) — можно несколько
- В режиме `文` появятся подтемы — кликни нужные (мультиселект), или оставь всё
- Кнопка `⟳` — перемешать колоду заново
- В футере: `全 N 文` / `全 N 字` / `全 N 問` — размер текущей базы

**Режим `文`:** клик на `答え` → показывается японский текст, фон карточки белеет.

**Режим `字`:** пиши прямо в белом квадрате по одной черте.

- правильная черта зеленеет и остаётся, неправильная краснеет, поле вздрагивает и черта стирается
- в шапке карточки видно, какая черта ожидается: `черта 3 из 6`
- три промаха подряд по одной черте — она сама подсвечивается подсказкой
- `↶` в правом верхнем углу отменяет последнюю черту, `✕` сбрасывает всё
- `答え` показывает весь иероглиф анимацией, чтения и примеры слов; двойной клик по квадрату — проиграть заново
- `隠す` возвращает обратно к письму с того же места

**Режим `択`:** японское предложение с пропуском, под ним — что вставить, **только по-русски**:

```
ソラさんは二年生ですが、たけしさんは＿＿＿です。
                                     третьекурсник
```

- слово собирается целиком из отдельных кандзи, по порядку: `三` → `年` → `生`
- вариантов не четыре, а все кандзи выбранных уроков плюс всё, что встречается в пропусках
- в предложении может быть несколько пропусков — заполняются слева направо, активный подчёркнут, в подсказке активный выделен жирным
- неверная плитка краснеет и вздрагивает, счётчик ошибок растёт, вопрос остаётся
- **`подсказка`** работает в три нажатия:
  1. чтения кандзи, которые **уже стоят в предложении** (`新幹線（しんかんせん）行きます（いきます）`), плюс чтение загаданного слова
  2. перевод всего предложения
  3. подсветка нужной плитки
- когда слово собрано, появляется перевод и кнопка **`далее`** — сам ничего не перелистывает
- 15 вопросов за подход, в конце счёт, число ошибок и подсказок, кнопка «ещё раз»

## Данные — формат предложений

Все предложения хранятся в массиве `D`:

```javascript
const D = [
  {u: 1, t: "は+です", ru: "Я студент.", jp: "がくせいです。"},
  {u: 2, t: "これ",    ru: "Сколько стоит это?", jp: "これはいくらですか。"},
];
```

| Поле | Тип | Описание |
|------|-----|----------|
| `u`  | number | Номер урока |
| `t`  | string | Подтема (показывается в фильтре) |
| `ru` | string | Русский текст — показывается на карточке |
| `jp` | string | Японский текст — скрыт до клика |

**Правило:** предложения с くて (перечисление прилагательных) — только в юните 7.

## Данные — формат кандзи

```javascript
const K = [
  {u:10, k:"住", on:"じゅう", kun:"す", mean:"жить", n:7,
   w:[["住む","すむ","жить"],["住所","じゅうしょ","адрес"]],
   s:["M29.5,20.5c...", "..."]},
];
```

| Поле | Тип | Описание |
|------|-----|----------|
| `u`  | number | Номер урока |
| `k`  | string | Сам иероглиф |
| `on` / `kun` | string | Чтения через `・` |
| `mean` | string | Значение по-русски — показывается на карточке |
| `n`  | number | Число черт |
| `w`  | array | Примеры слов: `[слово, чтение, перевод]` |
| `m`  | string | Мнемоника: из каких частей собран или что нарисован. Показывается на карточке прописи и в режиме `覚` |
| `s`  | array | SVG-пути черт **по порядку написания**, viewBox `0 0 109 109` |

Пути черт — из [KanjiVG](https://kanjivg.tagaini.net/) (CC BY-SA 3.0). Достать новые:

```bash
curl -O https://raw.githubusercontent.com/KanjiVG/kanjivg/master/kanji/0XXXX.svg
```

где `0XXXX` — кодпойнт символа в hex с ведущим нулём (住 = U+4F4F → `04f4f.svg`).
Из файла берутся все атрибуты `d` у `<path>` в порядке следования — это и есть порядок черт.
Число черт всегда сверяется с таблицей 漢字表 в учебнике.

## Данные — предложения с пропусками

```javascript
const Q = [
  {u:10, jp:"ソラさんは二年生ですが、たけしさんは{0}です。",
   ru:"Сора второкурсница, а Такэси третьекурсник.",
   b:[["三年生","третьекурсник","さんねんせい"]]},

  {u:10, jp:"{0}まで新幹線で行きます。", ru:"До Токио поеду на синкансэне.",
   b:[["東京","Токио","とうきょう"]],
   f:[["新幹線","しんかんせん"],["行きます","いきます"]]},
];
```

| Поле | Тип | Описание |
|------|-----|----------|
| `u`  | number | Номер урока |
| `jp` | string | Предложение, `{0}` `{1}` — места пропусков |
| `ru` | string | Перевод всего предложения — вторая подсказка и показ после ответа |
| `b`  | array | По одному элементу на пропуск: `[слово, подсказка по-русски, чтение]` |
| `f`  | array | Чтения кандзи, уже стоящих в предложении: `[как написано, как читается]`. Первая подсказка. Можно пустой массив |

**Правило:** все кандзи внутри пропусков должны быть уже пройдены (уроки 3–10). Пул плиток собирается автоматически: кандзи выбранных уроков плюс все кандзи из пропусков, так что ничего заводить вручную не надо.

## Режим 覚 — как устроено заучивание

Один заход = **8 кандзи**, каждый прогоняется через четыре типа заданий:

| Тип | Что делаешь |
|---|---|
| Значение | большой кандзи → выбрать значение из четырёх; под вариантами показывается мнемоника |
| Чтение | слово из примеров → выбрать чтение из четырёх |
| Предложение | строка **из эпизода** с пропуском (если эпизода нет — предложение из `Q`), собрать из плиток |
| Письмо | написать по чертам, с той же построчной проверкой |

Ошиблась — задание возвращается в очередь через три шага, и кандзи помечается как «споткнулась». В конце захода каждый кандзи получает новый интервал.

### Интервалы

```javascript
const STEPS = [1, 3, 7, 16, 35];   // через сколько дней показать снова
```

Взяла без ошибок — интервал растёт на шаг. Ошиблась — сбрасывается в начало, покажется завтра. Пул следующего захода собирается так: сперва то, что пора повторить, потом ни разу не виденное, потом остальное.

### Где хранится прогресс

В `localStorage` браузера, ключ `shukudai-progress-v1`, по одной записи на кандзи: `{n: ступень, due: когда повторить, seen: когда видела}`.

**Важное ограничение.** Браузер не даёт хранилище страницам, открытым как локальный файл: в `data:`-превью оно заблокировано всегда, в Chrome по `file://` — тоже. Код это переживает (прогресс живёт до закрытия вкладки), и на экране завершения честно пишет об этом. Чтобы прогресс действительно сохранялся между днями, файл нужно открывать по `http(s)` — то есть где-то разместить.

## Интерфейс — одно место на все режимы

Все надписи, размеры колод, цвета и сборка кнопок лежат в объекте `UI` и трёх
помощниках рядом с ним — в начале скрипта. Трогать их в коде режимов не нужно.

```javascript
const UI = {
  show: '答え', hide: '隠す', undo: '↶', clear: '✕',
  hint: 'подсказка', next: 'далее', again: 'ещё раз',
  strokeNow: (i, n) => `черта ${i} из ${n}`,
  deck: { sentence: 10, kanji: 12, quiz: 15, pool: 40 },
  openBg: '#ffffff', right: '#3a9d6b', wrong: '#d9534f', ink: '#1a1a1a',
};
```

**`makeCard(i, unit)`** — оболочка карточки: фон из палитры, номер урока, анимация появления. Кладёт на элемент `card.theme` — три цвета именно этой карточки.

**`makeButton(kind, label, theme, title)`** — кнопка: `'mini'` круглая сверху, иначе широкая снизу.

**`paintButtons(btns, theme, open)`** — перекрасить кнопки под закрытую (цветную) или открытую (белую) карточку.

Поэтому «поменяй надпись на кнопке» или «сделай колоду в 15 карточек» — это одна правка в `UI`, и она сразу работает во всех трёх режимах и во всех уроках. Отдельно по режимам ходить не надо.

## Данные — эпизоды

Сцена с персонажами Genki, в которой кандзи урока встречаются в деле. Сюжеты взяты из самого учебника, поэтому грамматика и лексика совпадают с тем, что проходишь.

```javascript
const E = [
  {u:10, title:"冬休みの予定", ru:"Планы на зимние каникулы", scenes:[
    {jp:"夜、ホテルでお正月の話をしました。", ru:"Вечером в гостинице говорили про Новый год.",
     f:[["夜","よる"],["お正月","おしょうがつ"],["話","はなし"]], key:["夜","正"]},
  ]},
];
```

| Поле | Описание |
|------|----------|
| `title` / `ru` | Название эпизода по-японски и по-русски |
| `jp` / `ru` | Строка сцены и её перевод |
| `f` | Фуригана: `[как написано, как читается]` |
| `key` | Какие кандзи этого урока отрабатывает строка — из них делаются пропуски в режиме `覚` |

## Как добавить новый урок

Код менять не нужно — только данные. Три массива, в каждый дописываются записи с новым `u`:

1. **`D`** — предложения (подтемы берутся из раздела 文法 учебника, в том же порядке)
2. **`K`** — кандзи из таблицы 漢字表 этого урока, с путями черт из KanjiVG
3. **`Q`** — предложения с пропусками для режима 択

Пилюля урока появится сама: списки юнитов считаются из данных (`units` из `D`, `kanjiUnits` из `K`). Число черт у каждого кандзи стоит сверять с учебником — расхождение означает, что взят не тот символ.

## JS логика

### Состояние
```js
let mode = 'sentence';        // 'sentence' | 'kanji' | 'quiz'
let active = [];              // номера активных юнитов
let activeTopics = new Set(); // активные подтемы (только в режиме предложений)
```

### Ключевые функции

**`buildControls()`** — рисует пилюли юнитов. Список юнитов берётся из данных текущего режима: `units` (из `D`) или `kanjiUnits` (из `K`), поэтому в режиме кандзи видны только уроки, для которых кандзи заведены.

**`buildTopicRow()`** — строка подтем для активных юнитов. В режиме кандзи всегда пустая. При смене юнита `activeTopics.clear()`.

**`shuffle()`** — делегирует в `shuffleKanji()` или `buildQuiz()` по режиму, иначе выбирает 10 карточек пропорционально по темам или по юнитам.

**`shuffleKanji()`** — до 12 случайных кандзи из активных юнитов.

**`animateStrokes(svg)`** — рисует черты по очереди через `stroke-dasharray` / `stroke-dashoffset`. Длительность черты пропорциональна её длине (`getTotalLength() * 6` мс, минимум 170), между чертами пауза 60 мс.

**`attachWriter(o)`** — всё поведение поля для письма: ввод через Pointer Events (работает и мышью, и пальцем), проверка черт, подсказки, отмена, сброс, раскрытие ответа. Размер канвы подгоняется под `devicePixelRatio`. Черты хранятся в координатах KanjiVG (109×109), поэтому при любом размере поля рисунок и проверка совпадают.

**`buildQuiz()` / `renderQuiz()`** — режим `択`. Вопросы берутся из `Q`. Пул плиток = кандзи выбранных уроков ∪ все кандзи из пропусков всех доступных вопросов (не только показанных, иначе пул выдавал бы ответы). Если для выбранных уроков в `Q` ничего нет, падает на отдельные слова из `K`. Внутри `renderQuiz` живёт `refresh()` — обновляет пропуски, подсказки и счётчик без пересборки карточки, чтобы не менялся цвет и не сбрасывались анимации.

## Как устроена проверка черты

Сравниваем написанное с эталонным путём KanjiVG. Всё в системе координат 109×109, так что размер поля на экране ни на что не влияет.

1. Сырые точки сглаживаются скользящим средним по трём (`smooth`) — убирает дрожание пальца
2. И написанная черта, и эталон режутся на 16 равноотстоящих точек (`resample`, `targetPoints`)
3. `checkStroke` проверяет четыре признака:

| Признак | Допуск | Зачем |
|---------|--------|-------|
| Отношение длин | 0.40–2.20 | не засчитать огрызок или черту во весь квадрат |
| Начало | `clamp(len×0.45, 12, 22)` | черта должна начинаться там, где надо |
| Конец | тот же | ловит черту, написанную задом наперёд |
| Форма | `clamp(len×0.35, 9, 18)` | среднее расстояние по точкам **после совмещения по центроиду** |

Длина не проверяется у коротких черт (эталон меньше 14 единиц) — у точек и мелких откидных она неинформативна.

Начало и конец сверяются абсолютно: место и направление черты важны. Форма — после совмещения центроидов, чтобы небольшой сдвиг не штрафовался дважды.

**Замеры на эталонных чертах** (проигрывание всех 95 черт всех 14 кандзи как пользовательского ввода):

| Что проверяли | Результат |
|---------------|-----------|
| Точный ввод + дрожание ±2 | принято 100% |
| Сдвиг на 4 единицы (3.7% ширины знака) | принято 100% |
| Сдвиг на 8 единиц (7% ширины) | принято 100% |
| Сдвиг на 12 единиц (11% ширины) | принято 77% |
| Черта задом наперёд | отбраковано 98% |
| Не та черта по порядку | отбраковано 93% |
| Сдвиг на 26 единиц (24% ширины) | отбраковано 100% |

Если пороги окажутся не по руке — крутить `posTol` и `shapeTol` в `checkStroke`.

**`spinIcon(btn)`** — анимация кнопки `⟳`: reflow-трюк для перезапуска `transition` при каждом клике.

## Как добавлять

### Предложения
Найди блок `// ── УРОК N ──` и добавь строки в нужную подтему:

```javascript
{u:10, t:"〜つもりだ", ru:"Русский текст.", jp:"日本語。"},
```

### Кандзи
Добавь объект в `K` — порядок в массиве не важен, карточки всё равно перемешиваются.

Счётчик в футере обновляется автоматически (`D.length` / `K.length`).
